---

## Assistant (Build · Eksekusi2 · 7.6s)

Login sebagai **superuser** ke Django Admin (`/admin/`), lalu:

1. Buka **Groups** → **Add group**, beri nama persis `Editor`, lalu simpan.
2. Buka **Users** → pilih pengguna → tambahkan grup `Editor` pada bagian **Groups** → simpan.

Pengguna itu bisa mengedit Project dan Blog pada permintaan berikutnya, tetapi tidak otomatis mendapat akses ke Django Admin.
